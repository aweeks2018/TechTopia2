# TechTopia2

NeoForge mod workspace for Minecraft 26.2.

## Prerequisites

- 64-bit Microsoft OpenJDK 25: https://learn.microsoft.com/en-us/java/openjdk/download#openjdk-25
- VS Code with Extension Pack for Java (`vscjava.vscode-java-pack`)
- A Minecraft Java Edition account that can run the target version
- A NeoForge-enabled test profile or the generated Gradle run configuration

NeoForge 26.2 is the current target at the time this workspace was created. The
mod loader and Minecraft version must match the modpack you want to support.

## First run

1. Open this folder in VS Code.
2. Confirm VS Code is using JDK 25, then reload the Gradle project.
3. Run `gradlew.bat build` from PowerShell. The launcher downloads Gradle
	automatically the first time. The first build downloads Minecraft,
	mappings, and NeoForge and can take a while.
4. Run `gradlew.bat runClient` to launch a development client.
5. Test `gradlew.bat runServer` as well. Accept the EULA in `runs/server/eula.txt`
	only after reading and agreeing to Mojang's EULA.

The built mod JAR is written to `build/libs` and can be copied to the `mods`
folder of a matching NeoForge instance.

## Project layout

- `src/main/java`: Java source code
- `src/main/resources`: textures, language files, and mod metadata
- `src/main/templates`: metadata expanded by Gradle during the build
- `src/generated/resources`: data generated by the `runData` task

## CurseForge release checklist

1. Create a CurseForge account and a new Minecraft mod project.
2. Upload a release JAR from `build/libs` and select Minecraft 26.2 and
	NeoForge in the project settings.
3. Add a logo, description, license, changelog, and screenshots.
4. Test the uploaded file in a clean profile and in the target modpack before
	marking it as release-ready.

CurseForge project creation, moderation approval, and API credentials require
your account and cannot be completed from this workspace. Do not commit an API
key; store it in a local secret manager or CI secret if automated publishing is
added later.

Official docs: https://docs.neoforged.net/docs/gettingstarted/
